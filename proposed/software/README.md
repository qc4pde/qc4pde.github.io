## Purpose 

The Software & Tooling committee exists to support the research efforts of the consortium via portable and reusable frameworks, components, and processes. 

These activities may include but is not limited to:

- frameworks for PDE solvers, pre- and post-processors

- functional algorithmic components for such frameworks

- interoperability via incorporation of other community tools (e.g. QASM, OpenQSE)

- tooling in support of metadata gathering for comparability of results over time (e.g. case parameters, code / library versions, quantum hardware calibration)

- use of modern AI software engineering tooling to author and support the above software in the face of rapid technical change

- technical support for the consortium's code and data repositories (but not including data ownership or stewardship)
